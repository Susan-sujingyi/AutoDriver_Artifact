# LPS22HB v2 判分依据

仅供宿主审计，不进入 agent 输入。依据为 ST DocID027083 Rev6 原文、冻结 Tock HIL/实际消费者及明确的物理配置。原参考已在未改动的 v1 中通过41项；这只是正控制，不是评分依据。

| 检查族 | 依据、处置和允许差异 |
| --- | --- |
| LPS-ABI | board.patch只分配8字节、I²C/Alarm并注册、启动驱动，替换温度/压力消费者接线，没有实现寄存器协议。实际编译约束保留，不强制公开BUFFER_SIZE或startup的额外返回类型。 |
| LPS-CONFIG | 原题选择1Hz连续温度/绝对压力、BDU开、附加低通/FIFO关。Rev6 pp37–39的字段和条件约束；LPFP_CFG在滤波禁用时是don't-care，SPI模式和未连接中断不强制等于参考。软件offset/reference功能未选择，不允许改变测量物理含义。 |
| LPS-NUMERIC | pp10、15、45–46：24bit二补码压力/4096hPa，16bit二补码温度/100°C。实际TemperatureClient为centiC、PressureClient为u32 hPa；独立Fraction计算。温度恰为原始有符号整数，无额外舍入。压力允许floor/ceil及1个整数LSB的有限计算偏差，不当作仪器物理精度。超物理量程的编码极值只测oracle，不要求unsigned接口输出负绝对压力。 |
| LPS-BDU | p37两条脚注明确规定PRESS_OUT_H最后读；I²C+BDU时IF_ADD_INC必须0且output只允许单字节读。p38正文明确output直到PRESS_OUT_H读取才可更新。因此整体保留直到PH并非纯粹来自参考。保留明确的总线约束和同一通道字节完整性；不强制每次请求都读全部5字节或两个通道回调必须来自同一次转换。 |
| LPS-DATA | pp37–38连续转换、保留完成值及BDU。任意合法温度/压力字节顺序、合法分笔读取、已完成样本缓存都可用。数值与已实际读取的完整同通道值比较；输入稳定改变后的有界进展单独验证。旧每次request必须更大generation、返回后全局idle被移除。 |
| LPS-DA | p45定义P_DA/T_DA与每ODR更新，但未精确规定哪个读取字节清除。名义模型采用高字节清除，同时以首字节清除做旁路压力检查。不把该细节当成资料已证明的协议错误，不要求固定先查两个ready位。读取清除ready不擦除实际输出。 |
| LPS-I2C | p26称SUB最高位无意义且IF_ADD_INC控制增量；p27末段又称SUB7要置1，多字节描述存在冲突。当前BDU选择禁止output burst，不用此冲突创造允许burst的新任务。单字节SUB7别名接受；指针分写后读取作为模型支持范围，尚未证明所有总线STOP相位的物理行为。 |
| LPS-ID | p36给WHO_AM_I；固定硬件选择不要求一定探测身份，错误器件响应单列诊断。 |
| LPS-CALLBACK | sensors.rs真实Temperature/Pressure HIL及temperature.rs/pressure.rs消费者。成功请求与正确通道回调对应；重复、无请求或拒绝后伪造回调为错误。并发允许拒绝或排队，不要求BUSY字面值。实际消费者不在callback内同步重入，故不新增该政策。 |
| LPS-PROGRESS | 1Hz是器件名义周期；4s、50000事件和宿主限额为评测监督界限，不伪称最大硬件响应时间。初始化后不要求全局idle；首个可接受请求另测，不能靠长等待掩盖未完成转换。 |
| LPS-RESET | SWRESET自清有原文依据，但原1ms模型不是数据手册保证最大值。保留1ms模拟刺激，若候选在未建模的复位重叠期间操作，报model_unsupported，不凭它断言候选硬件错误。BOOT内存重载等未覆盖行为同样区分。 |
| LPS-FAULT | 总线提交/完成错误、停测、启动失败与重试策略均记录为诊断；没有要求唯一恢复政策或固定错误码。到达与未到达注入点分开，诊断运行pass不等于已证明故障恢复正确。 |

资料可得性：配置及实际Tock接口三种条件都可得；原厂数字协议在D/SD，所选Zephyr实现及原宏在S/SD。资料消融不取消已证实硬件要求，也不补发人工规则。旧新ID、原始文件哈希和隐含断言逐项处置见benchmark/basis_v2/lps22hb.json。

v2 为29核心（20数值、2首个请求、2并发、2边界一致性、1交替通道输入变化、2同通道持续输入变化）、17诊断和2模型自检。有限波形不能证明所有缓存策略、总线相位、故障恢复或物理精度；没有真机结论。

稳定输入进度监督进一步明确为 8000000 µs，与单请求完成窗口分开。绝对截止时间传入每次采样，轮询与回调后观察均裁剪到剩余时间；内层请求不得隐式延长外层窗口。该限额用于有界复测，不是传感器物理时限。旧草案与检查结果保留，冻结时以 profile.json 和当前 harness 为准。
