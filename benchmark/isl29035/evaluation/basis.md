# ISL29035 v2 判分依据

宿主审计，不能进入 agent 输入。设备依据为 FN8371 Rev3.00（2016-12-12）原 PDF/text；目标依据为实际 AmbientLight/I²C/Alarm HIL、ambient_light capsule、应用固定板级patch后的 component。原参考在原 v1 复跑31/31，通过只作控制证据。

| 检查族 | 依据、修订及允许差异 |
| --- | --- |
| ISL-ABI | component 实际分配3字节、注册总线/Alarm/光照客户端，并启动一次。保留编译和资源约束，去掉额外公开常量与startup返回类型要求。 |
| ISL-CONFIG | 本实例保留 continuous ALS、4000lux、8-bit选择。p12 Tables7/9/10/11给出字段与0.41ms名义积分时间。无中断引脚时不把中断持久性字段等于参考值作为主功能要求。仅所选量程和分辨率构成转换前提。 |
| ISL-NUMERIC | p13–14 Eq1–3，以及 AmbientLightClient 的整数lux。独立分数oracle推导，不从IR或参考取值；允许邻近整lux量化。符号、量程、分母、端点和全宽usize错误仍可检出。 |
| ISL-WIDTH | p12说明8-bit结果为D0–D7，但没有规定本型号在8-bit模式下D8–D15会出现0xa5。旧模型给上字节注入非零值，把实现必须屏蔽这些位变成隐含条件。新核心采用零扩展名义帧；非零未用高位单列模型压力诊断，不声称这些位实物上必然非零或必然为零。正常两字节读取/组装不能因此被误拒绝；错误字节序仍由非零低字节向量检测。 |
| ISL-DATA | p8、12连续转换并在每个转换周期刷新，p10允许字节或burst读。8-bit任务只需要低字节，不增加整体两字节同epoch要求。保留已完成数据，不强制每请求新generation；先前转换和分笔读取可用。寄存器指针/未覆盖读写效果遇到边界单列模型不足。 |
| ISL-ID | p13 ID仅B3–B5有效，保留位可变；BOUT是上电/欠压历史状态，建议初始化时清除，并非转换ready位。身份探测、保留位处理、BOUT确认单列诊断，不用它们替代读数功能检查。没有选择欠压恢复功能，也不伪造未清BOUT就不能测量的行为。 |
| ISL-CALLBACK | HIL是标量lux，没有异步错误通知。健康成功请求要对应结果；禁止无请求/重复回调。并发允许拒绝或排队；消费者未在callback里调用下一次读，故不加入无依据的严格同步重入政策。 |
| ISL-PROGRESS | 按物理稳定输入变化检查实际采样可用性；100ms、50000事件、进程时间是监督限额，未完成不等同于违反芯片时序。上电与创建驱动的时间分开，不要求所有后台事件停止。 |
| ISL-FAULT | I²C同步/异步错误、scalar HIL的能力限制。允许重试/已有值策略；精确错误码、全局idle、固定时间恢复不再作为隐含数值要求。故障是否实际到达、发生什么输出及是否仍有请求等待均记录。 |

源配置仍使用实际已准入宏文件，目标配置只描述物理选择。S提供源码及生效配置，D提供原文，SD共同提供；所有条件目标工程、配置及判分相同。数学来源在D/SD，源实现证据在S/SD，HIL在全部条件。旧说明中的源码错误和通道分析不交付模型。

v2 为16核心（13数值、最早可接受请求、并发、稳定输入变化）、12诊断和2模型自检。旧31项映射单列。光学精度、真实欠压、电源噪声及所有总线相位没有被软件测试证明；软件验收和冻结状态见总报告。

稳定输入进度监督进一步明确为 400000 µs，与单请求完成窗口分开。绝对截止时间传入每次采样，轮询与回调后观察均裁剪到剩余时间；内层请求不得隐式延长外层窗口。该限额用于有界复测，不是传感器物理时限。旧草案与检查结果保留，冻结时以 profile.json 和当前 harness 为准。
