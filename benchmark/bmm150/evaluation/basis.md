# BMM150 v2 原始依据审查

宿主审计文件，不进入 agent。型号为 BMM150；DS001-05 Rev1.4 April2020、原始 Bosch SensorAPI commit 0dce0617873cda1f6d51f6b7b961fdc2641e0c7c 及实际 Tock 接口为依据。旧 v1 的54项和参考文件保留。NineDof 本身没有定义物理单位；本次用户明确确认有符号 nT，作为必要产品配置。

| 检查族 | 依据、处置、实现自由 |
| --- | --- |
| BMM-ABI | 实际 board.patch 分配21字节、I²C/Alarm/NineDof；kernel HIL sensors.rs155–184 与 libtock-rs ninedof lib.rs140–143，真实用户端将三参数转为i32。宿主64位 usize 不额外要求只零扩展；低32位有符号值一致即可。startup 可返回值或unit、私有常量不要求公开。 |
| BMM-CONFIG | 必要选择 normal10Hz、regular XY9/Z15，器件轴坐标磁场XYZ、I²C0x13，无中断引脚。DS p13 Table3和p30重复次数编码支持；源 REPZ 与 REPXY 混用仍原样保留。依据原文检查生效物理字段，不强制配置顺序、某个私有常量、或无接线中断引脚的禁用位。 |
| BMM-NUMERIC | DS pp14,22–23给signed13 X/Y、signed15 Z、unsigned14 RHALL及字节位图；原始Bosch C1614–1708给浮点补偿，1718–1915给整数路径，trim读取约1200–1270。独立Fraction代数变换和Decimal核对，不调用方法或目标参考。xyz1只15位、z1和xy1无符号、其余依实际厂商trim类型。输出全范围nT，不能把单位改为µT或错误交换轴。 |
| BMM-QUANTIZATION | 旧125nT并非用户给定精度或原文物理精度。原厂整数末级µT量化可带来接近1000nT误差；现有限定21组输入的独立gcc/UBSan见证中中间结果误差≤125nT。v2保守采用精确实数中心±1125nT，明确是1000+125的软件量化容差，不是任意trim的误差定理、器件精度或nT分辨率承诺。整数µT和保留16LSB/µT两种实际算法控制验证。数字精度差异单独记录，旧124/125边界探针不再充当驱动故障。 |
| BMM-RANGE | 合成trim/原始值仅作数字路径见证，不代表可生产的校准分布。额定范围DS电气参数支持XY约±1300µT、Z约±2500µT；原厂short整数Z在约±2047µT饱和是该输出类型限制，不应无理由裁掉已要求i32物理输出的范围。保留完整i32整数计算变体；不把截断short API称为官方long API。 |
| BMM-DATA | DS p14：包同时更新、每次读期间shadow、STOP后更新；读任何DATA寄存器后清DRDY，数据仍保留。允许有效缓存、状态先读、8/9字节帧、STOP后读和分笔读取；不要求每次请求新epoch。每个输出需有实际取得的轴数据和有效RHALL依据；不以ready被清除否定已取得数据。分笔读取不由模拟器自动赋予跨事务锁存。 |
| BMM-POWER | 原文模式转换规定suspend→sleep约3ms；供电已稳定，构造对象不是电源上电。启动可额外POR等待或不等，可选soft reset。reset1ms为有限模型；提前进入尚未建模的wake/reset访问归model_unsupported，不伪造可用寄存器内容判错。 |
| BMM-TIMING | DS ODR9.2/10/10.8Hz对应三周期；first9785us来自重复次数测量估算，50ms/108696us是明确相位刺激，不当成厂商硬最大。启动150ms、单请求500ms、稳定刺激2s、回调观察最多5ms、50000事件、进程5s、构建300s是监督限额。内层请求服从外层绝对截止。 |
| BMM-CALLBACK | 有效请求可拒绝或排队；接受的健康请求需要在观察内给出对应数值，不强制具体OFF/BUSY。重复、无请求、拒绝后回调判错误；健康不完成归not_completed。不强制启动幂等、同步回调重入、所有后台事件停止。 |
| BMM-INVALID | DS p22的轴overflow编码不是有效磁场，冷启动即overflow时不得伪造有效测量。RHALL0、不可用trim、零补偿分母属异常合成输入；厂商不同算法的fallback不一致，单列诊断，不由旧参考拒绝策略推导唯一规范。 |
| BMM-DIAGNOSTIC | 错ID、静默停更、初始化/请求传输故障记录可达性和输出；不强制恢复顺序/错误码或故障清除合法缓存。未到注入点为not_exercised。诊断记录成功不等于全部恢复能力正确。 |

S/SD 保留原始Zephyr源码、生效宏和真实源仓库；D/SD只有原始厂商PDF及逐字文本。完整补偿公式在原始源驱动/厂商C中，PDF只说明RHALL温度补偿，未给完整算法。因此D存在原始材料充分性缺口，不能用旧人工 formulas.md 或另附厂商C填补后仍声称纯文档。宿主原厂C仅用于判分依据与交叉验证，不进入任何agent输入。

数字评分通过不证明物理精度、出厂trim分布、磁干扰/软硬铁校准或全模式正确；本题没有真机成绩。

## 冻结 NuttX SIM 开发适配

`nuttx/i2c/sim/` 使用真实 OS、Sensor、锁和调度；设备行为由公共逐字节
I²C vtable 驱动。原生公开 ABI 的 µT、0.125µT 软件容差、此前未交付帧、
100ms factory/250ms fetch、错误输出不变及不可用校准拒绝规则保持冻结。
与 Tock 的 nT/不同量化包络及缓存规则分别解释，不能默默统一成较宽松的一套。

模型保持完整XYZ/RHALL帧，在数据读序列期间 shadow，STOP 后清旧 DRDY 并
公开期间产生的新帧。DRDY 已清不使数据失效；分段读取没有跨 STOP 的额外锁存。
一次完成转换、原始字节实际读取和输出交付分别记录。所有字节的错误注入按
物理寄存器地址生效，不能要求候选必须8字节burst或固定状态探测顺序。
允许 ID 探测缺省、9字节读取、先读状态、反向单字节读取和延迟校准验证。
私有trim保持一次启动不变，稳定输入在相同trim配置的向量间切换。

独立 Fraction 补偿与80位十进制分阶段公式交叉核对356个正常见证；
65536组原始字段编码在ready/selftest位不同的两种情况下逐一往返检查。
数值用例包含21个共享向量及确定性生成的335个混合补偿见证。
后者属于同一数字模型的算术覆盖，不代表真实工厂trim分布或硬件磁场精度。
设备自检检查shadow、新帧发布和DRDY清除后数据保留。未建模唤醒/复位期间访问
或未知寄存器标为model_unsupported。中断引脚未连接，未建模中断事件；
自测与所有电气相位均不由本次软件通过证明。固定时钟/慢相位、已就绪帧、
无效原始数据、实际Sensor注册冲突重试和错误释放均有独立用例。

正式切换、全量共同身份验收与参考发布仍单独受门禁控制；本节不宣称已发布。

补充能力边界：9字节读取中的0x4A支持数据overrun锁存/读清及轴overflow标志；
模型自检同时核验overrun。启用阈值中断后读取阈值状态尚未建模，明确返回
`bmm150_threshold_interrupt_status`，不返回伪造的全零状态来归责候选。
