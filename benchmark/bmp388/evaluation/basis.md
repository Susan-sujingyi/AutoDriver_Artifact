# BMP388 v2 评分依据

本页仅供宿主，不进入 S/D/SD。原始依据为 Bosch BST-BMP388-DS001-07、Revision 1.7、November 2020，实际 Tock HIL/消费者和固定接线。原参考保持字节不变，v1 的 115 项结果保留，不能追认为 v2。

| 检查族 | 原始依据、允许差异及处置 |
| --- | --- |
| BMP-ABI | 实际 board.patch 分配 21 字节、绑定 I²C/Alarm/温度/压力接口并启动一次。sensors.rs 的温度 centiC、气压 hPa 是输出单位。固定目标编译检查真实调用；不额外要求公开私有常量、startup 精确返回类型、幂等启动或回调内重入。 |
| BMP-CONFIG | 精确 BMP388，I²C 0x76、normal/25Hz、P4x/T1x、IIR/FIFO/中断关闭来自必要功能配置。数据表 pp36–38 的 PWR_CTRL/OSR/ODR/CONFIG 定义使这些选择可判定；只检查有定义字段。未找到“所有保留位必须写零”的一般条文，故未知保留位行为归 model_unsupported，不能将旧断言直接称物理错误。 |
| BMP-NUMERIC | p28 Table23 列出 21 字节校准系数的符号/位宽，pp55–56 给量化系数与温度/压力多项式。独立 Fraction 展开并以 100 位 Decimal Horner 交叉检查，既不读 IR 也不调用参考。判据是精确物理量 ±1 个目标整数单位，允许截断、最近整数、f64/f32 以及其他满足此误差的算术。真实测量精度与整数舍入容差分开。 |
| BMP-RANGE | Table1 的 −40..85°C、300..1250hPa 用于正常行为输入。25 组校准分布与原始 ADC 样例是合成数学见证，不声称来自量产器件。旧宽度/溢出极端只验证 oracle。新增同校准、同时改变温度和压力的见证用于检测混合数据，仍在额定范围。 |
| BMP-DATA | pp32–33 DATA 为 unsigned24 little-endian，STATUS 的 drdy_press/temp 在各自任一数据寄存器被读后清除，但并没有使保留的数据失效。允许读取保留值、按需校准、跨通道缓存；不强制 ID、全部校准一次读完、每次新 epoch 或每次读取 DRDY。温度只需自身三字节；压力补偿需可用温度，可来自数值相同的先前完整温度采集，不强制无意义的 epoch 相等。 |
| BMP-SHADOW | p27 §3.10–3.10.1 明确单次 burst 内一致，独立读需与转换周期同步。模型在事务起点锁定本次读的值，在事务结束后公布期间完成的新值。保留合法同步分读变体，不把所有分读判错。转换边界测试保持 nominal 40ms 周期，将请求放在既定下一转换前 250µs，而非缩短器件周期；同一次测试同时改变 P/T，避免将“不同 epoch 但数值完全相同”误报错误。 |
| BMP-BUS | p41 §5.2.1 为地址/值成对写，§5.2.2 明确允许 STOP 或 repeated START 后自动递增读。支持单寄存器、多组配置、分段校准和 STOP 后读。不能把普通地址后连续数据的写协议套到该器件。未知寄存器/特殊接口选项单列不支持。 |
| BMP-TIME | p7 的上电首通信 2ms 与软复位完成不是同一证明；§3.1/p33 EVENT 可标识复位完成。模型初态已上电稳定，reset 延时 2ms 只是已声明模型选择，提前操作报不支持。p26 Table22 对 P4x/T1x 最大转换 12.48ms，25Hz 的 nominal 周期 40ms；ODR 精度容差未完整模拟。不要求唯一轮询步长；150ms 充分等待控制仍能通过。 |
| BMP-IDENTITY | 固定实物型号明确时没有依据要求每个驱动必须探测 ID。0/60/FF 的替代型号诊断不纳入该器件核心成绩；删除 ID 探测及仅取消 ID 断言均可通过正常任务。 |
| BMP-CALLBACK | 实际 HIL 的请求与回调关联、类型和缓冲所有权仍保留。重复/错通道/同步拒绝后回调为 fail，健康采样拒绝或不完成为 not_completed；并发可拒绝或排队。不强制全局 idle、OFF/BUSY 或参考的回调重入顺序。 |
| BMP-PROGRESS | 请求 500ms、初始化 100ms、稳定输入 2s、回调后最多 5ms、每次推进 50,000 事件及宿主 5s/构建 300s 都是监督限额。进度绝对截止时间传入内层请求，不能借新窗口。通过其他通道预热后重复请求，永久缓存无法靠交替访问刷新另一通道而逃过检查。 |
| BMP-FAULT | p31 ERR 的命令/配置错误读清，fatal 是另一状态；没有证据据此强制擦除全部历史样本、固定错误码或一次特定恢复流程。传输故障、停 ready 标志、设备错误、命令未就绪和初始化故障旁路观察，保留触发与回调安全证据。诊断运行成功不代表完整故障恢复。 |

S 提供实际源驱动和生效配置；D 提供原始文档，其附录本来含厂商公式和代码，保留原文不算研究者提示；SD 是并集。HIL、实际集成和必要物理配置三种条件相同。旧人工合同、公式摘要和源错误提示均不进入输入。

两个 OS 后端的能力边界补记：§4.3.6 定义 0x0C–0x0E 为 24 位 Sensor Time。当前执行器尚未实现该时钟的推进、读锁存及复位语义，读取覆盖这些寄存器的事务必须报告 `model_unsupported`，不能用全零寄存器替身推导候选缓存或新鲜度错误。初态为电源已经稳定；软复位后的 2ms 区间仍只是模型选择，提前访问同样报告不支持。合法参考变体分别检查“不额外等待上电”和“读取 Sensor Time”，前者必须通过，后者用于确认能力边界被明确报告，不算驱动缺陷对照。Tock 的旧 `skip_por_wait` 不再列为缺陷控制；删去额外上电等待是当前初态下允许的实现。

当前 76 核心、35 诊断、3 模型自检。核心包括新增一致性见证的两个数值通道；分母并非为了复刻旧 115 项。完整映射及旧隐含断言审查在 benchmark/basis_v2/bmp388.json。行为模型没有证明任意厂商校准、任意时钟/ODR 偏差、物理精度或真机可靠性。
