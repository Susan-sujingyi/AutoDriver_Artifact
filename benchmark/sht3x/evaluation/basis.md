# SHT30 v2 依据与模型边界

本页仅供宿主审计。实物型号为SHT30，任务键沿用sht3x。Sensirion SHT3x-DIS December2022 Version7及实际Tock温湿度消费者是来源，旧合同/参考本身不是裁决依据。

| 检查族 | 依据与处置 |
| --- | --- |
| SHT-ABI | 实际component分配6字节并绑定Temperature/Humidity/I²C/Alarm、启动一次。保留编译约束；不强制公开BUFFER_SIZE、固定startup返回值、幂等重启或同步callback重入。 |
| SHT-CONFIG | 保留single-shot/high repeatability/no clock stretching/heater off。CRC是已有任务保留的数据完整性功能选择，在精简配置中只写选择，不写多项式/布局。原文pp9–10说明读方向CRC可选，所以不能声称所有SHT30应用都必须检查CRC。 |
| SHT-NUMERIC | p14 §4.13定义unsigned16信号、65535分母、温度−45+175ST/65535和RH100SRH/65535。HIL需centiC和centipercent。独立Fraction式与CRC长除法，不调用参考/IR。接收与精确量相差至多1个目标整数单位的量化；不伪称能检出全部小于该阈值的数学近似。 |
| SHT-RANGE | pp2–7规定温度−40..125°C，RH0..100%。旧raw0/65535温度为−45/130°C；旧1/255/256也低于−40°C。保留这些编码的oracle与诊断，核心采用额定范围，并在25°C配上RH端点/低位以保留湿度边界覆盖。不能把合理拒绝额定范围外值误判为采样错误。 |
| SHT-TIME | pp6–7 Tables4–5：高重复性最大15ms(≥2.4V)或15.5ms(低供电)，典型12.5ms；覆盖8/12.5/15/15.5ms刺激，不把典型当最小值。无clock stretch时未完成read返回NACK，支持等待或NACK轮询。两命令间1ms来自p9，软复位1.5ms来自Table4；早到返回模拟NACK，允许驱动重试，不捏造数据。 |
| SHT-POWER | 创建驱动前电源可已稳定，核心采用已上电状态；真实上电/复位时间另有文档与模型检查。不要按构造函数时间再强制一次POR wait。 |
| SHT-DATA | pp9–10一条single-shot命令产生一对值，可在任意字节NACK终止，温度可只读取前三字节。完整湿度需跳过温度/CRC后取得自身数据。允许已验证值缓存和跨通道复用，不强制每次新epoch，不因后来传输错误擦除先前真实观测的数值依据。 |
| SHT-CRC | pp13–14/Table20：每两个数据字节分别CRC，0xBEEF→0x92。核心故障刺激在初始化前设置，避免把合法已缓存的好值误判成忽略新错误。只保护被使用的通道；全帧校验与仅使用通道校验均合法。错误值的禁止输出是有界安全观察，不声称该观察证明了无限等待、重试或全部故障恢复。未实际读取到故障帧记not_exercised。 |
| SHT-CALLBACK | 正常接受的请求必须给对应结果；重复/错通道/拒绝后回调为错误。并发允许拒绝或排队。标量湿度保留完整usize校验，不按有符号32位截断掩盖极大数；温度有异步Err，健康数据未交付记not_completed。 |
| SHT-PROGRESS | 250ms、50000事件、宿主进程/编译时限为监督政策。稳定输入变化检出永久缓存，允许有限缓存。超限不等于数据手册违例。 |
| SHT-FAULT | 停测、传输错误、重复startup和缓存恢复策略旁路记录，不要求一种错误码或固定恢复行为。未覆盖serial/alert配置等命令报model_unsupported；已知错误测量模式报配置错误。 |

输入仅含目标配置、真实集成目标与S/D/SD原始材料。所有温湿度单位来自真实HIL，而非额外接口映射。评分原始文件哈希、检查映射和隐含断言处置单独存于basis。此阶段为评测维护，不作为AutoDriver未见题成绩。

稳定输入进度监督进一步明确为 1000000 µs，与单请求完成窗口分开。绝对截止时间传入每次采样，轮询与回调后观察均裁剪到剩余时间；内层请求不得隐式延长外层窗口。该限额用于有界复测，不是传感器物理时限。旧草案与检查结果保留，冻结时以 profile.json 和当前 harness 为准。
