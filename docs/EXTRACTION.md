# 提取范围

保留 44 道原生任务的定义、源选择、配置、PDF、公共构建支持、当前隐藏参考和独立评分代码；保留 AutoDriver 新方案 `implementation/system/`、通用接口及必要的主机执行代码。OS 快照、离线 wheels、Cargo vendor、许可证和来源信息随包保留。

未包含原工程的 `run/`、`result/`、图表、论文、开发计划、虚拟环境、Git 历史、生成知识库、旧 `zephyr2tock` 方法、其他方法及其私有依赖、专用实验控制器、历史接受证书、旧候选重放与跨发布复评工具。

打包调整包括：

- 运行入口只接受 AutoDriver；live 使用 SD，框架契约在每题内重新生成。
- 共享运行层移除其他方法的启动、知识库和会话恢复分支。
- `.env` 提供无真实账号信息的占位版本，权限为 0600，并被 Git 忽略；可提交模板为 `.env.example`。费用配置同样要求使用者自行填写并确认。
- JSON 格式的大型来源清单直接使用 JSON 解析，YAML 文件仍使用 YAML 解析，避免每次逐题校验重复慢速解析。
- 重新生成本分发的资源清单与内容身份。`status: extracted` 仅代表固定分发内容，不继承原多方法发布的资格或性能结论。
- 保留冻结源验证 receipt 中的原始输入身份、编译器和范围元数据，移除历史输出路径。源验证器本身及其绑定的原始输入未更改；实验开始时只核验，不重编源 OS。
- 清空候选特定的历史错误原因注册表，不改任务、参考源码、设备模型或判分规则。
- 新增离线安装、回归、公共输入交接、代表参考原生构建/评分及显式内容快照入口；检查产生的临时记录不作为分发输入。

`EXTRACTION.json` 记录原样保留的 AutoDriver 生产文件身份与源任务身份。完整资源身份见 `third_party/sources.lock`，当前运行文件身份见 `manifest.json`。

benchmark 中厂商来源说明和源验证元数据用于固定材料，属于任务定义的一部分。它们不是实验运行数据，也不向方法暴露隐藏参考、厂商补充信息或评分反馈。源资料处理副本的披露见 `source-authenticity.md`。
