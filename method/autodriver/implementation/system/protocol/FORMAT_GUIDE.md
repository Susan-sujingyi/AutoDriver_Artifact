# 调用产物与公共语义接口

本文件给出阶段调用概览，不包含器件实例、参考实现或评分数据。完整 v0.1 语言目录见 LANGUAGE_SPEC.md：公共 19、FP 22、DBC 31、BP 36 个构造器。生产参数与检查范围见 IMPLEMENTATION_PROFILE.md。当前内核已执行部分类型、单位、引用、表达式、FSM、时间/数据/资源检查；未支持或未建立的性质保持 unknown，不能把解析成功当作设备正确。

模型每次自动收到响应协议解释和公共语义，以及输出/读取契约所需的 FP、DBC、BP 语言。语义来自这些定义，不能假设模型凭名称理解。未定义的名称不得发明，确有新能力需求须请求语言扩展。

- FP 根为 `FrameworkProfile(...)`：平台/版本/条件、API 要求与保证、事件及资源协议、时间和输出编码。
- DBC 根为 `DeviceContract(...)`：适用条件与已选策略、类型化布局/校验/物理关系、设备交互与采集行为、假设和未决项。
- BP 根为 `BindingPlan(...)`：父契约引用、动作/事件/数据/资源及请求绑定、实现选择、派生义务和缺口。

`Sequence` 在前一步成功后推进；`Lifecycle` 组织初始化与采集关系。事务具有开始、接受、拒绝、完成等阶段；它们不是同一事件。`WaitAfterCompletion` 引用当前操作的指定成功完成事件，并约束下一设备动作的最早时刻。`ReadFrame` 使用所引用布局与完整性要求；`CommitValidatedSample` 只接受当前采集的完整有效数据。失败不能默认恢复可采集状态；`Unspecified` 保留未知，不授权任意行为。

公式采用受限类型化表达式，物理关系与位向量解码的语义区分。FP 定义原生单位和资源保证，BP 引用后实现；同一事实不在多个层次独立重写。只有相关原语目录和语义已提供时才能输出对应构造器；缺少定义则请求证据或报告未决。

公共前后条件可由原语定义一次；必要的额外不变量和进展条件需有依据。原语展开后的 FSM 属于同一模型，不能另行手写成第二份规范。

代码产物为候选 `file_edits`。replace/delete 必须匹配当前基线 hash，create 必须不存在，所有路径位于当前允许的 target 范围。规范 patch 和提交身份由主机生成。输出候选不等于编译成功或行为正确。
